Claude Bridges

De bridge laat Claude Code met een expliciet gekozen model werken. De uitvoering bewaart een taakdossier, begrenst pogingen en looptijd, en controleert of de CLI een volledig resultaat teruggeeft. Cursor gebruikt zijn eigen CLI.

Wat verandert

  • Geen automatische verdeling of fallback. Kies een rail en één model; ontbrekende modellen stoppen vóór de agent start.
  • Een mislukte poging wordt nooit automatisch herhaald. Hervatten gebeurt alleen op verzoek, in dezelfde sessie.
  • Dubbele context telt één keer mee. Ontbrekende of te grote context geeft een fout, geen stille afkapping.
  • Exitcode 0 is onvoldoende: het gestructureerde eindresultaat moet compleet zijn. Een afgekapt antwoord, geweigerde tool of ontbrekend resultaat telt als onvolledig.
  • De Grok-proxy gebruikt standaard maximaal twee gelijktijdige verzoeken; geannuleerde wachtrijverzoeken worden verwijderd vóór upstreamuitvoering.

Installeren

Vereist: Python 3.10+, Git Bash voor de shell-wrapper, de relevante CLI en voor Grok Node.js. De Python- en Node-code gebruikt alleen standaardbibliotheken. Voer CLI-aanmeldingen uit op het gewenste abonnement.

  1. Installeer CLIProxyAPI apart en gebruik cliproxy/config.example.yaml als uitgangspunt. Controleer actuele modelnamen bij je provider. De voorbeelden garanderen geen beschikbaarheid.
  2. Voor Grok: meld aan met de Grok CLI en start grok-auth-proxy/grok-auth-proxy.js. Deze leest je lokale Grok-login. Voor Codex kan scripts/codex_auth_import.py de bestaande CLI-login importeren, of gebruik de device-login van CLIProxyAPI.
  3. Kopieer delegate/delegate.conf.example naar ~/.delegate.conf. Vul de lokale router-key, de gewenste modellen en zo nodig een native seat in. MODEL_ROUTER_KEY is de lokale bridge-key; OpenRouter gebruikt daarnaast zijn eigen API-key in de proxyconfig.
  4. Gebruik voor deze versie delegate/delegate.sh uit deze checkout. Een andere kopie in een orchestratiemap wordt hierdoor niet bijgewerkt.

De runner start of herstart geen services. Bestaande services en live configuratie veranderen niet door de broncode bij te werken. Controleer vóór een latere activatie welke checkout en configuratie de service gebruikt.

Een taak starten

PowerShell, vanuit deze checkout. Vervang het voorbeeldmodel door een model uit je bridgecatalogus. Read Grep Glob geeft alleen die tools vooraf toestemming; niet-toegestane Claude-tools vragen in deze uitvoering geen interactieve toestemming.

$env:DELEGATE_TASK_ID = 'review-parser'
$env:DELEGATE_CWD = 'C:/werk/mijn-repo'
& 'C:/Program Files/Git/bin/bash.exe' ./delegate/delegate.sh codex 'Read Grep Glob' C:/werk/opdracht.txt 'model-uit-catalogus'

Voor een native Claude-seat definieer je bijvoorbeeld SEAT_WERK="-" in de configuratie en gebruik je werk als rail. Voor Cursor gebruik je cursor, lege tools en een expliciet Cursor-model. Cursor heeft eigen toolrechten; een ontbrekende native CLI leidt niet meer tot een automatische WSL-uitwijk. Binnen WSL kun je dezelfde runner met daar geïnstalleerde CLI's gebruiken.

Een bridge-aanroep gebruikt standaard ~/.claude-bridge als aparte Claude-configuratiemap. Stel BRIDGE_CONFIG_DIR in wanneer jouw bestaande bridge een andere map gebruikt. Native seats behouden hun opgegeven configuratiemap; overgeërfde Anthropic API-routing wordt verwijderd.

Hervatten

Inspecteer eerst task.json, de output van de laatste poging en de werkbestanden. Zet vervolgens DELEGATE_RESUME=1 en herhaal dezelfde opdracht met dezelfde taak-ID. Er gaat een korte hervatinstructie naar de bestaande sessie; de oorspronkelijke context wordt niet opnieuw als nieuwe taak ingestuurd.

$env:DELEGATE_RESUME = '1'
& 'C:/Program Files/Git/bin/bash.exe' ./delegate/delegate.sh codex 'Read Grep Glob' C:/werk/opdracht.txt 'model-uit-catalogus'

Model, tools, context, configuratiemap, werkmap en limieten moeten gelijk blijven. Een veranderde Git-branch of commit blokkeert hervatten. Een voltooid taak-ID wordt niet opnieuw uitgevoerd. Een procescrash die de status op running laat staan vereist handmatige inspectie van eventuele nog actieve processen; de runner neemt een onbekende lopende taak niet automatisch over. Na inspectie kan de operator een nieuwe afgebakende opdracht maken voor het resterende werk.

Limieten en verbruik

InstellingDefaultWerking
DELEGATE_MAX_ATTEMPTS3Totaal aantal expliciet gestarte pogingen per taak.
DELEGATE_MAX_SECONDS900Totale CLI-looptijd; resterende tijd gaat mee naar hervatten.
DELEGATE_MAX_INPUT_BYTES65536Opdracht plus expliciet toegevoegde context, na deduplicatie.
DELEGATE_MAX_OUTPUT_BYTES16777216Output en stderr per poging; gecontroleerd tijdens uitvoering.
DELEGATE_MAX_REPORTED_TOKENSNiet ingesteldBlokkeert een volgende poging bij bereikt budget of onbekend eerder verbruik.

Dit is geen harde tokenstop tijdens een modelverzoek. De CLI kan vóór het eindresultaat al meer tokens hebben gebruikt. De invoerlimiet omvat niet de verborgen systeemprompt, repo-instructies, MCP-definities, toolresultaten of een bestaande sessie. De uitvoerlimiet wordt periodiek gecontroleerd en kan kort overschreden worden. CLI-interne API-retries vallen binnen de looptijd, maar worden niet als aparte runnerpogingen geteld.

Het taakdossier telt de door de CLI gerapporteerde input-, output- en cachetokens uit modelUsage, inclusief daarin opgenomen subagents. Hoofdagent-verbruik uit usage wordt alleen als gedeeltelijke telling bewaard. Ontbrekende velden en nulgezette crashtellingen blijven onbekend; total_tokens blijft dan leeg. Een abonnement betekent niet dat deze telling een factuurbedrag is. verification: not_run blijft staan: een voltooid modelantwoord bewijst geen correct uitgevoerde opdracht.

Context en lokale gegevens

DELEGATE_CONTEXT bevat één bestandspad per regel, ook op Windows. De bestaande delegate_context-functie mag aanvullende paden teruggeven. De opdracht blijft vooraan staan; context wordt als bronmateriaal toegevoegd en krijgt geen instructie om de opdracht te overrulen.

Het taakdossier staat standaard onder delegate/state/<taak-ID>. Elke poging bewaart de ingestuurde tekst, volledige CLI-output en stderr lokaal. Deze kunnen gevoelige inhoud bevatten. De manifestgegevens bevatten onder meer inhoudshashes, bronpaden, sessie-ID, Git-status en verbruik. Ze zijn geen vervanging voor een Git-backup of transactielog. Houd een aangepaste DELEGATE_STATE_DIR buiten gedeelde of gesynchroniseerde mappen.

DELEGATE_SENSITIVE=1 blokkeert Grok, Codex-via-proxy, OpenRouter en Cursor. Een optionele SENSITIVE_RE controleert de volledige expliciete invoer inclusief context. Deze controle inspecteert geen toekomstige toolreads en is geen datalekbeveiliging op OS-niveau. Gebruik voor gevoelig werk de toegestane native seat.

Grok-proxy

Defaults: GROK_MAX_CONCURRENCY=2, GROK_MAX_QUEUE=200, GROK_QUEUE_WAIT_MS=180000, GROK_SOCKET_TIMEOUT_MS=300000, GROK_MAX_BODY_BYTES=4194304. Ongeldige numerieke configuratie stopt de startup. Grote bodies krijgen 413; ongeldige JSON krijgt 400 vóór er upstreamwerk start. Wachtrijafwijzingen geven 503 met Retry-After: 5. Een afgebroken stream sluit de downstreamverbinding en geeft het slot vrij.

Controleren

python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test-proxy.cjs

De tests gebruiken tijdelijke bestanden, een fixture-CLI en lokale HTTP-servers. Ze controleren uitvoering, sessieherstel, privacygrenzen, budgets en de proxyverbindingen zonder providerkosten. Ze bewijzen geen live providercompatibiliteit, hogere antwoordkwaliteit of een gemeten percentage tokenbesparing.
